# Data

## AI4I 2020 Predictive Maintenance Dataset

Source:
UCI Machine Learning Repository

Dataset:
AI4I 2020 Predictive Maintenance Dataset

Original file:
data/raw/ai4i2020.csv

The file stored inside `raw/` must not be manually modified.

All cleaning, preprocessing, feature engineering, and transformations
must be performed programmatically and stored in `data/interim/`
or `data/processed/`.
